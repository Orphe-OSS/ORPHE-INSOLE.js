# `lib/` — browser client for ORPHE INSOLE 1.5

This folder builds the single committed file the showcase loads at runtime:

```
lib/insole-1.5.web.js   # IIFE bundle, exposes window.Insole15 (committed)
```

The showcase page (`../index.html`) loads that file with a plain `<script>` — like
the SDK's `dist/`, the showcase itself needs **no build step**. You only rebuild the
bundle when the client or proto changes.

## What's inside

| Path | Origin |
|---|---|
| `src/ble/WebBluetoothTransport.ts` | vendored from bleRPC `central_web` (Web Bluetooth GATT transport) |
| `src/client/BlerpcClient.ts` | vendored from bleRPC `central_web` (protocol client, transport injected) |
| `src/client/knownKeys.ts` | vendored from bleRPC `central_web` (localStorage TOFU store) |
| `src/client/GeneratedClient.ts` | generated by bleRPC `tools/generate-handlers` from `insole.proto` |
| `src/proto/insole.{js,d.ts}` | `pbjs`/`pbts` static module from `insole.proto` |
| `src/client/InsoleClient.ts` | device-specific: friendly config, live `get_window` monitor, gait monitor (`get_gait_live`), RPC serialization |
| `insole.proto` | copy of the firmware's `proto/insole.proto` (private) |

The container/command/encryption layers come from [`@blerpc/protocol-ts`], which runs
unmodified in a browser (only `@noble/*` WebCrypto + `TextEncoder`/`DataView`).

## Rebuild

```bash
cd lib
npm install
npm run proto      # regenerate src/proto/insole.* from insole.proto (only if the proto changed)
npm run typecheck
npm run build      # -> ./insole-1.5.web.js
```

If `insole.proto` changes, also regenerate `src/client/GeneratedClient.ts` from the
bleRPC repo:

```bash
# in a checkout of github.com/tdaira/blerpc
go run ./tools/generate-handlers --root /tmp/gen \
  --proto /path/to/insole.proto --options /path/to/insole.options \
  --out-ts-client "$PWD/.../lib/src/client/GeneratedClient.ts"
```

## API (`window.Insole15`)

```js
const client = new Insole15.InsoleClient(); // encryption + TOFU pinning on by default
const [dev] = await client.scan();               // opens the browser device chooser (user gesture)
await client.connect(dev);                        // negotiation + X25519/Ed25519 key exchange
const cfg = await client.getConfigInfo();         // { deviceIdHex, foot, firmwareVersion, ... }
await client.startMonitor((frame) => { ... });    // { t, serial, press[6], acc{xyz}, gyro{xyz},
                                                   //   quat{wxyz}, euler{pitch,roll,yaw} }
// quat/euler are ESTIMATED on the client (Madgwick IMU fusion) — the device
// streams no orientation.
client.stopMonitor();
// Gait analysis (firmware GaitAnalysisCore): opens a measurement session and
// polls get_gait_live; one callback per completed stride. Runs alongside the
// sensor monitor — every RPC is serialized inside the client (bleRPC is not re-entrant).
await client.startGaitMonitor((stride) => { ... }); // { strideSeq, strideLength, strideHeight, speed,
                                                   //   cadence, contactTime, pronation, strikeAngle,
                                                   //   landingForce, gaitType, footStrike, steps, distanceM }
await client.stopGaitMonitor();                     // stop_measurement -> firmware logs the session summary
client.disconnect();
```

Chrome/Edge only, over HTTPS or `localhost`.
