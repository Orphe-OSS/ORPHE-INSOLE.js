TOOLKIT EXAMPLE / REALTIME PRESSURE + IMU

おいしいうどんを作ろう！

足上げを加速度・ジャイロで、踏み込みを6ch圧力で検出します。ふみふみするほど生地がもちもちになり、 1歩ごとの強度・左右バランス・ペースを下に表示します。

WAITING
INSOLE を接続してください タイトル横のスイッチから、左右1台ずつ接続します。1台でも遊べます。
このゲームを遊ぶときは、Toolkit UI の歯車を開き、次のように設定してください。

Data Outputs: Raw Sensor Data をON Raw Data Acquisition: Realtime Realtime Streaming Format: 3: gyro + acc + press (200Hz) このデモプログラムでは初期設定で上記の設定となっています

センサ未接続のあいだはデモデータを自動再生します。接続すると自動でデモを止め、START ボタンが出ます。 右下のアイコンでフルスクリーン、Esc かもう一度アイコンで戻ります。

ONE STEP AT A TIME

踏み込みの統計

1歩ごとに「足上げの高さ × 踏み込みの強さ × タイミング」から強度を算出します。 目標は500ms前後で踏み込むことです。

  • 踏み込みを検出すると、強度・左右バランス・ペースの評価がここに出ます。

強度は無次元の指標です。 圧力は6ch ADC生値の合計を使うため、体重や装着具合で絶対値が変わります。 個人内での変化を見る用途に向き、個人間の比較や絶対評価には使えません。 しきい値が体格に合わないと感じたら THRESHOLDS を調整してください。

HOW IT WORKS

このexampleが使う Toolkit の設定プログラム

buildInsoleToolkit(toolkit, "INSOLE 01", 0, {
  profile: "realtime-pressure",   // 3: gyro + acc + press (200Hz)
  autoReconnect: true,
  onStateChange(snapshot) {
    updateConnectionSource(snapshot);
  }
});

const insole = insoles[0];
insole.setup();
insole.gotConvertedAcc  = function (acc)   { latest.acc = acc; };
insole.gotConvertedGyro = function (gyro)  { latest.gyro = gyro; };
insole.gotPress         = function (press) { detectStep(this.id, press); };
